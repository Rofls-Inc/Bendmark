# analyzer

Анализатор. Python.

По результату прогона находит предел сервиса.

## Как считается предел

Ступени проверяются по порядку. Ступень считается отказом, если выполнено хотя бы одно:
- p99 больше порога (`--p99-ms`, по умолчанию 500 мс);
- пропускная перестала расти: прирост пропускной, делённый на прирост целевой нагрузки относительно предыдущей ступени, меньше `--min-gain` (по умолчанию 0.5). Для первой ступени сравнение идёт с нулём, то есть проверяется `throughput / target`.

Предел - целевая нагрузка последней ступени перед первым отказом. Если отказа не было, то предел не найден и известна только нижняя оценка - нагрузка последней ступени.

Входные данные - `result.json` (пример - `examples/result.json`).

## Запуск

Нужен Python 3.10+. Команды выполняются из `services/analyzer`.

```bash
python -m analyzer ../../examples/result.json
python -m analyzer ../../examples/result.json --p99-ms 300 --min-gain 0.5
```
